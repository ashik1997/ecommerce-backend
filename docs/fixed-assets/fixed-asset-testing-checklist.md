# Fixed Asset Testing Checklist

- Create category and warehouse location.
- Create an asset; warehouse must be required.
- View tag print page.
- Assign available asset and confirm it cannot be double assigned.
- Return assigned asset.
- Transfer asset from one warehouse to another and receive it.
- Create and complete maintenance job.
- Preview depreciation for YYYY-MM.
- Post depreciation once; duplicate period should be blocked by database unique rule.
- Dispose asset and confirm it cannot be assigned again.
- Check warehouse-wise report.
- Confirm route access is protected by your existing permission middleware.
